## 工程质量

不绑里程碑、持续推进的质量基线（详见 `.qmllint.ini` 与 `tests/`）：

| 项 | 状态 | 说明 |
|---|---|---|
| QML 静态检查 | ✅ 0 警告 | `qmllint` + `.qmllint.ini`，`MaxWarnings=0`，**无任何降级例外** |
| QML 组件测试 | 🔄 12 / 26 | Qt Quick Test，每个 `tst_*.qml` 独立一个 ctest 项 |
| C++ 单元测试 | ✅ 3 项 | ThemeManager / IconRegistry / ShadcnTableModel |
| 打包消费验证 | ✅ | `make consumer-smoke`：安装前缀 + 独立工程 `find_package(QtShadcn)`，CI 每次跑 |

> lint 门禁只看**最低支持版本**（CI 跑 Qt 6.8）。本地 Qt 6.11 全绿不代表 6.8 全绿 ——
> 引用 QtQuick 的成员前先查 `plugins.qmltypes` 的 `revision`，`>= 1536` 即 6.9+，一律不能用。
