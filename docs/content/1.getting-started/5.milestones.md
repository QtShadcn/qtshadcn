# 里程碑

| 阶段 | 内容 | 状态 |
|---|---|---|
| **M0** | 仓库骨架：根 CMakeLists + `src/qml` 模块 + `src/core` + showcase 空应用 | ✅ 完成 |
| **M1** | Theme 基础层：C++ ThemeManager + light/dark tokens + `QtShadcnTheme` + showcase 色板页 | ✅ 完成 |
| **M2** | Button 组件（variant / size / disabled / loading） | ✅ 完成 |
| **M3** | Card / Input / Badge / Switch / Tabs / Dialog | ✅ 完成 |
| **M4** | Icon 系统 + Animations | 🔄 进行中（Icon ✅ / Animations ⏳） |
| **M5** | C++ Models / Table、WindowManager | ⏳ 计划 |
| **M6** | 文档站完善 + README + 发布 | 🔄 进行中 |

每个里程碑独立可构建、可运行验证（showcase 承载）。

## 组件计划（GitHub issues #1-10）

每批一个组件，对应一个 GitHub issue，实现完关闭对应 issue。见 [组件开发流程](/development/component-workflow)。

## 当前已落地组件

| 组件 | 说明 |
|---|---|
| `QtShadcnTheme` | 声明式主题入口（M1） |
| `ShadcnButton` | 6 variant × 5 size，loading / 键盘焦点环（M2） |
| `ShadcnButtonGroup` | 按钮组：合并边框 + 分隔线 |
| `ShadcnToggle` / `ShadcnToggleGroup` | 切换按钮，支持 `exclusive` 单选 |
| `ShadcnSpinner` | 加载指示器（Button loading 内部使用） |
| `ShadcnCard` | 纯组合组件：CardHeader / Content / Footer，size default/sm（M3） |
| `ShadcnInput` | 基于 QQC.TextField：36px 高 + 6px 圆角 + 聚焦环 |
| `ShadcnBadge` | 6 variant，胶囊形，destructive 透明底红字（v4） |
| `ShadcnSwitch` | 44×20 / 28×16 双尺寸，胶囊轨道 + 滑块动画 |
| `ShadcnTabs` | TabsList + TabsTrigger + TabsContent，default/line 双 variant |
| `ShadcnDialog` | 居中 448px + 阴影 + fade/zoom 动画 + 自定义 header/footer |
| `ShadcnIcon` | lucide 图标：本地精选 74 个 + 远程兜底（CDN 拉取 + 磁盘缓存），随主题变色（M4） |
| `IconRegistry` | C++ 图标注册表：qrc 加载 + 远程下载 + 缓存，`dataUrl(name, color)` 供 QML 直接用 |
