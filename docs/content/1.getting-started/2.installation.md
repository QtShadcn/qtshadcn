## 环境要求

- Qt 6.5+（本机开发环境：Qt 6.11.1 @ `~/Qt/6.11.1/macos`, Apple Silicon arm64）
- CMake 3.24+

## 获取源码

```bash
git clone https://github.com/QtShadcn/qtshadcn.git
cd qtshadcn
```

## 构建

```bash
# 一键构建（默认 QT_PREFIX=$HOME/Qt/6.11.1/macos，可用环境变量覆盖）
make build

# 运行 showcase（Design Token 色板 + 组件展示，明暗切换）
make run
```

或手动：

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="${QT_PREFIX:-$HOME/Qt/6.11.1/macos}" -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build
QML_IMPORT_PATH="build/src:build/examples/showcase" ./build/bin/showcase
```

> [!TIP]
> 本机多 Qt 版本共存时，用 `QT_PREFIX` / `-DCMAKE_PREFIX_PATH` 指定版本。Linux 用 `gcc_64`，Homebrew 用 `$(brew --prefix qt)`。

## 在你的项目里使用

`find_package(QtShadcn)` 尚未提供。把本仓库放到 `third_party/qtshadcn` 后 `add_subdirectory`（作为子项目时默认不编 showcase）：

```bash
mkdir -p third_party
git submodule add https://github.com/QtShadcn/qtshadcn.git third_party/qtshadcn
```

```cmake
find_package(Qt6 REQUIRED COMPONENTS Core Gui Quick Qml QuickControls2 Svg Network)
add_subdirectory(third_party/qtshadcn)
target_link_libraries(myapp PRIVATE QtShadcn Qt6::Quick Qt6::QuickControls2)
```

`main.cpp` 必须 `QQuickStyle::setStyle("Basic")`。运行时 `QML_IMPORT_PATH` 指向 `build/third_party/qtshadcn/src`（QtShadcn 模块目录的父路径）。

```qml
import QtShadcn

Window {
    QtShadcnTheme { id: theme }
    ShadcnButton { text: qsTr("Deploy") }
}
```
