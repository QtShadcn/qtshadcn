## 环境要求

- Qt 6.5+（本机开发环境：Qt 6.11.1 @ `~/Qt/6.11.1/macos`, Apple Silicon arm64）
- CMake 3.24+

## 获取源码

```bash
git clone https://github.com/QtShadcn/qtshadcn.git
cd qtshadcn
```

## 构建

```bash
# 一键构建（自动探测 ~/Qt/6.11.1/macos，可用 QT_PREFIX 覆盖）
make build

# 运行 showcase（Design Token 色板 + 组件展示，明暗切换）
make run
```

或手动：

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH="$HOME/Qt/6.11.1/macos" -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build
QML_IMPORT_PATH="build/src:build/examples/showcase" ./build/bin/showcase
```

> [!TIP]
> 本机多 Qt 版本共存时，用 `-DCMAKE_PREFIX_PATH` 指定版本；`find_package(Qt6 6.8)` 兼容本地 6.11.1。

## 在你的项目里使用

```cmake
# 通过 qt_add_qml_module 引入 QtShadcn 模块后
find_package(Qt6 COMPONENTS Quick Qml QuickControls2 REQUIRED)
add_subdirectory(third_party/qtshadcn)
target_link_libraries(app PRIVATE QtShadcn)
```

```qml
import QtShadcn   // QML 模块 URI

ShadcnButton {
    text: "Deploy"
}
```
