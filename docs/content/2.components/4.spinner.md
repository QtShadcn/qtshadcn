旋转的加载指示器（圆环动画），`ShadcnButton` 的 `loading: true` 内部即用它。

## 用法

```qml
ShadcnSpinner {
    width: 14
    height: 14
    color: theme.foreground
}
```

## 说明

- 圆环 + 旋转动画，颜色可任意指定（默认跟随文字色场景）
- 通常与 `loading` 状态配合，也可独立用作页面加载指示
