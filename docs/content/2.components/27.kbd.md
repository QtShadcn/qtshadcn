键盘快捷键标签：等宽字体 + 边框 + 圆角。

## 用法

```qml
ShadcnKbd { text: "⌘K" }
ShadcnKbd { text: "Ctrl" }
```

## 视觉

- 背景 `theme.muted` + 边框 `theme.border` + 圆角 4px
- 11px 等宽字体（SF Mono / Menlo）
- 内边距 6px 垂直、12px 水平
