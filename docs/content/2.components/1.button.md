基于 QQC.Button（Basic style），只替换视觉与 API，保留键盘导航 / Focus / 无障碍。

![ShadcnButton 效果展示](/images/components/button.png)


## 用法

```qml
ShadcnButton {
    text: qsTr("Deploy")
    variant: ShadcnButton.Variant.Primary   // Primary / Secondary / Outline / Ghost / Destructive / Link
    size: ShadcnButton.Size.Medium          // ExtraSmall / Small / Medium / Large / Icon
    iconName: ""                            // 可选：lucide 图标（显示在文本左侧）
    loading: false
    onClicked: console.log("clicked")
}
```

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `variant` | enum | `Variant.Primary` 实心主色 / `Secondary` 次色 / `Outline` 描边 / `Ghost` 幽灵 / `Destructive` 危险 / `Link` 链接（hover 下划线） |
| `size` | enum | `ExtraSmall`(24) / `Small`(28) / `Medium`(32) / `Large`(36) / `Icon`(32)，对齐 shadcn v4 base |
| `iconName` | string | lucide 图标名（见 IconRegistry.names），16px 随文字色 |
| `loading` | bool | 显示 Spinner 并禁用交互，文字半透明 |
| `enabled` | bool | 继承 QQC，禁用态整体 50% 透明度 |

## 状态

- **hover**：primary 等实心变体按亮度混入背景色（等效 shadcn hover:bg-*/90）；outline/ghost hover 用 accent 底 + accentForeground 字
- **pressed**：混合比例加重
- **focus**：Tab 可达，3px ring 焦点环
- **组合**：配合 `ShadcnButtonGroup` 自动合并边框

## 示例

```qml
Row {
    spacing: theme.spacingSm
    ShadcnButton { text: qsTr("新建"); iconName: "plus" }
    ShadcnButton { text: qsTr("导出"); variant: ShadcnButton.Variant.Outline; iconName: "download" }
    ShadcnButton { text: qsTr("删除"); variant: ShadcnButton.Variant.Destructive; iconName: "trash-2" }
    ShadcnButton { text: qsTr("保存中"); loading: true }
}
```

## 尺寸对照

对齐 shadcn v4 base / style-nova 的 `.cn-button-size-*`（旧版按 v3 口径偏大一整档）：

| size | 高度 | 横向内边距 | 图标-文字间距 | 字号 | 内联图标 |
|---|---|---|---|---|---|
| `ExtraSmall` | 24 (`h-6`) | 8 (`px-2`) | 4 (`gap-1`) | 12 (`text-xs`) | 12 (`size-3`) |
| `Small` | 28 (`h-7`) | 10 (`px-2.5`) | 4 (`gap-1`) | 13 (`text-[0.8rem]`=12.8，Qt 取整) | 14 (`size-3.5`) |
| `Medium` | 32 (`h-8`) | 10 (`px-2.5`) | 6 (`gap-1.5`) | 14 (`text-sm`) | 16 (`size-4`) |
| `Large` | 36 (`h-9`) | 10 (`px-2.5`) | 6 (`gap-1.5`) | 14 (`text-sm`) | 16 (`size-4`) |
| `Icon` | 32 (`size-8`) | — | — | — | 16 (`size-4`) |

圆角不写死：`Medium`/`Large`/`Icon` 取 `theme.radiusLg`（= `rounded-lg` = `--radius` 本身），
`ExtraSmall`/`Small` 取 `min(theme.radiusMd, 10/12)`（= `rounded-[min(var(--radius-md), …)]`）。
这些派生值都在 `QtShadcnTheme` 里（`radiusSm/Md/Lg/Xl`），改主题 `radius` 按钮与弹窗一起跟动。
