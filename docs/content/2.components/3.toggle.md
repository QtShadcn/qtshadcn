可切换状态的按钮（outline 样式 + checkable），选中时 accent 背景高亮。

## 用法

```qml
// 独立切换
ShadcnToggle { text: qsTr("粗体"); checked: true }
ShadcnToggle { text: qsTr("斜体") }

// 多选组（默认）
ShadcnToggleGroup {
    ShadcnToggle { text: qsTr("左") }
    ShadcnToggle { text: qsTr("中"); checked: true }
    ShadcnToggle { text: qsTr("右") }
}

// 单选组（exclusive: true）
ShadcnToggleGroup {
    exclusive: true
    ShadcnToggle { text: qsTr("单选 1"); checked: true }
    ShadcnToggle { text: qsTr("单选 2") }
}
```

## 说明

- **多选**：`ShadcnToggleGroup` 默认 `exclusive: false`，任意切换
- **单选**：`exclusive: true`，同组仅一个 on
- 组内互斥由 QQC ButtonGroup 提供（onCompleted 手动收集子项）
- 也兼容 `ShadcnButtonGroup`（toggle 是 checkable 按钮）
