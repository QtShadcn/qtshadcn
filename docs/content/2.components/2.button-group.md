按钮组容器：子项直接放 `ShadcnButton` / `ShadcnToggle`，自动合并相邻边框、只保留两端圆角。

## 用法

```qml
ShadcnButtonGroup {
    ShadcnButton { text: qsTr("A"); variant: ShadcnButton.Variant.Primary }
    ShadcnButton { text: qsTr("B"); variant: ShadcnButton.Variant.Primary }
    ShadcnButton { text: qsTr("C"); variant: ShadcnButton.Variant.Primary }
}
```

## 说明

- 组内按钮 `spacing: -1` 重叠 1px，无 border 的 variant（如 Primary）中间自动加 1px 分隔线
- 圆角只保留两端的 `first` / `last`，中间为直角
- 子项数量动态变化时自动重新分配圆角（`_groupPosition`）
