---多行文本输入（Flickable + TextEdit + ScrollBar 实现），内容超高可内部滚动。

## 用法

```qml
// 基础：行数多时随内容增高
ShadcnTextarea {
    width: 340
    placeholderText: qsTr("输入多行内容...")
}

// 限高内部滚动：内容超高钳住高度，滚轮/滚动条滚动
ShadcnTextarea {
    width: 340
    maxHeight: 150
    text: qsTr("长内容...")
}

// 不限高（shadcn field-sizing-content 行为）
ShadcnTextarea {
    width: 340
    maxHeight: 0
}
```

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `text` / `placeholderText` | string | 文本 / 占位（mutedForeground 色，自绘） |
| `maxHeight` | int | 高度上限（默认 200）：超过则内部滚动；`0` = 不限高 |
| `selectByMouse` | bool | 鼠标拖选 |
| `enabled` | bool | 禁用态 opacity 50% |

## 说明

- 高度 = `max(64, min(自然高度, maxHeight))`（min-h-16 起）
- 内部滚动由 Flickable 提供（滚轮 / 触摸 + 可见滚动条）
- 不基于 QQC.TextArea（其内部无 Flickable，TextEdit 原生不响应滚轮滚动内容）
