基于 QQC.Dialog（Basic style），对齐 shadcn v4 Base UI 默认产物（`.cn-dialog-*`）：384px 宽 + rounded-xl + `ring-1`（无阴影）+ 遮罩 10% + fade/zoom 100ms + 内置 ghost 关闭钮 + 可滚动 body + 底部 sticky muted footer。

## 用法

```qml
ShadcnButton { text: qsTr("打开"); onClicked: dialog.open() }

ShadcnDialog {
    id: dialog
    modal: true   // 默认

    ShadcnDialogContent {
        ShadcnDialogHeader {
            ShadcnDialogTitle { text: qsTr("确认操作？") }
            ShadcnDialogDescription { text: qsTr("此操作不可撤销。") }
        }
        // 业务内容（超高时 body 内部滚动，footer 固定）
        footer: ShadcnDialogFooter {
            ShadcnButton { text: qsTr("取消"); variant: ShadcnButton.Variant.Outline; onClicked: dialog.close() }
            ShadcnButton { text: qsTr("确认"); variant: ShadcnButton.Variant.Destructive; onClicked: dialog.close() }
        }
    }
}
```

> `ShadcnDialogFooter` 必须赋给 `footer:` 属性。直接写成普通子节点会落进默认的 body 属性，
> 跟着正文一起滚动，失去 sticky 效果。

## 子组件

| 组件 | 说明 |
|---|---|
| `ShadcnDialogHeader` | 头部（Title + Description 垂直堆叠，gap 8 = `gap-2`） |
| `ShadcnDialogTitle` | 标题（text-base） |
| `ShadcnDialogDescription` | 描述（mutedForeground） |
| `ShadcnDialogContent` | 内容容器：可滚动 body + sticky muted footer 条；`maxHeight` 可自定义（默认 85% 窗口高） |
| `ShadcnDialogFooter` | 底部按钮区（右对齐，gap 8 = `gap-2`），通过 `footer:` 传入 |

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `showCloseButton` | bool | 右上角 ghost 关闭钮（默认 true） |
| `modal` | bool | 模态（默认 true） |
| `overlayOpacity` | real | 遮罩不透明度，默认 `0.10`（对齐 `bg-black/10`）；配色偏深的主题可调到 `0.3` |
| `maxHeight` | int | Content 的高度上限（超过则 body 滚动、footer 固定），默认 0.85×窗口高 |

## 规格对照

| 项 | shadcn v4 base | 本组件 |
|---|---|---|
| 宽度 | `max-w-sm` = 384 | 384 |
| 圆角 | `rounded-xl` = `--radius`×1.4 | `theme.radiusXl`（默认 radius 8 → 11） |
| 边框 | `ring-1 ring-foreground/10` | 1px + 前景色 10%（light/dark 同一档） |
| 阴影 | 无（v4 用 ring 取代 `shadow-xl`） | 无 |
| 遮罩 | `bg-black/10` | `overlayOpacity: 0.10` |
| footer | `bg-muted/50` + `border-t` + `rounded-b-xl` + `p-4` | 同（仅底部圆角，顶边直角） |
| 关闭钮 | `absolute top-2 right-2`，icon-sm = 28px | 28×28，距边 8px |

## 说明

- **关闭**：Esc / 点击遮罩 / 右上角 ✕
- **动画**：fade + zoom-95，100ms
- **居中**：相对整个窗口居中（`Overlay.overlay`）
- footer 为 sticky muted 条（border-t + bg-muted/50 + 仅底部圆角），长内容时固定不动
- 对话框按内容自然撑开；内容放得下时**不会**出现滚动条（视口高度恒等于 contentHeight），超出 `maxHeight` 才滚动
- **未实现背景模糊**：shadcn 的 overlay 还带 `backdrop-blur-xs`(4px)，Qt 没有 `backdrop-filter`。试过「遮罩里用 ShaderEffectSource 取应用纹理」和「给应用根项挂 layer.effect」两条路，前者在独立渲染层拿不到基层纹理，后者会把整棵应用树拉成离屏纹理、与其他 layer/popup 交互不稳，4px 的收益不值这个风险，暂时只做压暗。真要做建议走 C++ 抓窗口帧再模糊贴回。
