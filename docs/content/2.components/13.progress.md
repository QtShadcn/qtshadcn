基于 QQC.ProgressBar（Basic style），对齐 shadcn progress 规范。

## 用法

```qml
ShadcnProgress { width: 360; value: 0.6 }          // 0..1
ShadcnProgress { width: 360; value: 0.3; showValue: true }   // 显示百分比
```

## 属性

| 属性 | 类型 | 说明 |
|---|---|---|
| `value` | real | 0..1（继承 QQC.ProgressBar） |
| `showValue` | bool | 在指示条内左侧显示百分比文本（primaryForeground 色） |

## 视觉

- **track**：12px `bg-muted` 胶囊
- **indicator**：`bg-primary`，宽度变化有 200ms 动画（transition-all）
- 连续增长（上传/安装）或确定性进度场景

## 相关

- 不确定进度（indeterminate）暂未实现，可用 `ShadcnSpinner` 替代
