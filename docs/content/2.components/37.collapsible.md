可折叠内容（shadcn/ui v4 base-nova 口径，对齐 Base UI `Collapsible`）。语义 = 单块可开合区，
没有 Accordion 的「互斥 / 多选」那一层，只有一个 `open` 布尔量：

```
Collapsible
├── CollapsibleTrigger        开合按钮
└── CollapsibleContent        可折叠内容（高度 0 ↔ 自然高动画 + overflow-hidden）
```

官方 registry 里这三件套是**零样式透传**（各自只有 `data-slot`，一个 `className` 都没有），
样式全靠调用方加。Qt 侧把这套视觉收在 Accordion 的同源实现里复用：
`ShadcnCollapsibleTrigger` 内部就是一个 `ShadcnAccordionTrigger`，
`ShadcnCollapsibleContent` 内部就是一个 `ShadcnAccordionContent`
（双 chevron 互斥、高度动画、收起后不可交互，两处永远一致）。

## 用法

```qml
ShadcnCollapsible {
    width: 460
    open: false                       // 受控布尔量
    onToggled: opened => console.log(opened)

    ShadcnCollapsibleTrigger { text: qsTr("筛选条件") }
    ShadcnCollapsibleContent {
        RowLayout {
            spacing: theme.spacingSm
            Text { text: qsTr("关键词"); color: theme.mutedForeground }
            ShadcnInput { Layout.fillWidth: true; placeholderText: qsTr("搜索…") }
        }
    }
}
```

想要 Accordion 那种行底分隔线时，套一层 `ShadcnAccordionItem` 即可，展开语义仍由
`Collapsible.open` 决定：

```qml
ShadcnCollapsible {
    width: 460
    ShadcnAccordionItem {
        ShadcnAccordionTrigger { text: qsTr("高级设置") }
        ShadcnAccordionContent { /* …… */ }
    }
}
```

## API

### ShadcnCollapsible

| 属性 / 信号 | 默认 | 说明 |
|---|---|---|
| `open` | `false` | 受控展开态。宿主写入即生效，点 trigger 同样回写 |
| `content` | — | 默认属性，收 `CollapsibleTrigger` / `CollapsibleContent`（或一个 `ShadcnAccordionItem`）进内部 `Column` |
| `toggled(opened)` | — | 用户点击开合时发出；宿主直接写 `open` 不发（受控写入不算用户动作） |

### ShadcnCollapsibleTrigger

| 属性 | 默认 | 说明 |
|---|---|---|
| `text` | `""` | 标题（转发给内部 `ShadcnAccordionTrigger`） |
| `expanded` | 只读 | 跟根的 `open` |
| `trigger` | — | 内部那个 `ShadcnAccordionTrigger`，需要覆盖视觉 / 接 `hovered` / 改 `enabled` 时用它 |

键盘可达性在 `trigger` 上（`Tab` 聚焦，`Enter` / `Space` 切换）—— 包装层本身是 `Item`，
不可聚焦，`forceActiveFocus()` 要打给 `trigger`。

### ShadcnCollapsibleContent

| 属性 | 默认 | 说明 |
|---|---|---|
| `expanded` | 只读 | 跟根的 `open` |
| `textColor` | `theme.mutedForeground` | 同 Accordion：CSS 继承色在 QML 里要宿主显式取 |
| `content` | — | 默认属性，直接透传给内部 `ColumnLayout` |
| `panel` | — | 内部那个 `ShadcnAccordionContent`（测试 / 宿主取动画中间值用） |

## 与 Accordion 的取舍

| | Collapsible | Accordion |
|---|---|---|
| 语义 | 一块区域，独立开合 | 一组互斥行，`value` 记录展开项 |
| 状态 | `open: bool` | `value: string / string[]` + `multiple` / `collapsible` |
| 分隔线 | 无（套 `AccordionItem` 才有） | 每行 `not-last:border-b` |
| 典型场景 | 筛选面板、"显示更多"、高级设置 | FAQ、设置分组、手风琴式表单 |

## 视觉与动画

视觉规格与 [`ShadcnAccordion`](/components/accordion) 完全同源（py-2.5 / text-sm font-medium /
rounded-lg / hover:underline / focus-visible ring / 双 chevron 互斥 / 200ms 高度动画），
细节和取舍读那一页。收起态内容 `clip` + `visible: false`，吃不掉点击。

## 已知偏差

- 官方 Collapsible 无默认样式，「与 accordion 同源」是本项目采纳的假设（核实方式：
  `registry/base-nova/ui/collapsible.tsx` 三个函数全部零 `className`，只有 `data-slot`）。
- 官方 `w-full` 在 Qt 没有级联宽度：给 `ShadcnCollapsible` 显式宽度。
