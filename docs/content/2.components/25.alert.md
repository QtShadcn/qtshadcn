提示框：4 variant（Default / Destructive / Warning / Success），图标 + 标题 + 描述。

## 用法

```qml
ShadcnAlert {
    title: qsTr("错误")
    description: qsTr("发生错误，请稍后重试。")
    variant: ShadcnAlert.Variant.Destructive
}
```

## 视觉

- 4 variant：default / destructive / warning / success
- 各 variant 自带语义色图标（alert-circle / check-circle / alert-triangle / info）
- 半透明背景 + 同色系边框 + 14px 加粗标题 + 13px 描述
