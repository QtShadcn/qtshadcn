悬停提示：鼠标悬停在元素上显示浮层提示。

## 用法

```qml
ShadcnButton {
    text: qsTr("悬停我")
    ShadcnTooltip.text: qsTr("这是一个简单的提示")
}
```

## 视觉

- 背景 `theme.popover` + 边框 `theme.border` + 圆角 `theme.radius`
- 12px 字号，最大宽度 200px 自动换行
- 跟随 QQC.ToolTip 原生 hover 行为
