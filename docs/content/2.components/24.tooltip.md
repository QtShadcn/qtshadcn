悬停提示：鼠标悬停在元素上显示浮层提示。

## 用法

```qml
ShadcnButton {
    text: qsTr("悬停我")
    ShadcnTooltip { text: qsTr("这是一个简单的提示") }
}
```

## 程序化显示

`open` 为 `true` 时忽略 hover 直接显示气泡，用于演示页、截图等没有鼠标的场景：

```qml
ShadcnTooltip {
    text: qsTr("常显提示")
    open: true
}
```

## 视觉

- 背景 `theme.popover` + 边框 `theme.border` + 圆角 `theme.radius`
- 12px 字号，最大宽度 200px 自动换行
- 自实现 hover 探测（`Popup` + 祖先 `hovered` 监听），300ms 延迟显示
- 气泡比触发器宽时按居中对齐，并向父容器内 clamp，避免溢出可视区
