验证码输入（shadcn Input OTP）。一个透明的 `TextField` 承接全部键盘输入（键入 / 粘贴 /
退格 / 输入法），文字按字符自绘到 N 个格子里。

## 用法

```qml
ShadcnInputOTP {
    length: 6
    onCompleted: function(value) {
        console.log("填满:", value)
    }
}
```

预填值：

```qml
ShadcnInputOTP {
    text: "123456"
}
```

## API

| 属性 | 默认 | 说明 |
|---|---|---|
| `length` | `6` | 格子数 = 字符上限；缩小它会立即裁掉多余字符 |
| `text` | `""` | 当前值（内部 `TextField` 的 `text` 别名）。写入超长会截断到 `length` |
| `enabled` | `true` | 禁用时 opacity 50%，且不响应点击 |
| `slotSize` | `32` | 每格边长（只读，shadcn `size-8`） |
| `charCount` | 自动 | 当前字符数（只读） |
| `activeIndex` | `-1` | 光标所在格；未聚焦或光标停在末尾时为 `-1`（只读） |

| 信号 | 说明 |
|---|---|
| `completed(string value)` | 刚好填满时发出一次；退格后重新填满会再发 |

辅助方法：`slotChar(index)` 取某格字符、`slotItem(index)` 取某格对象（测试/定制用）。

## 视觉

- 每格 **32×32**（`size-8`），边框 `theme.input`，字符 14px 居中
- **整体是一个圆角矩形**：首格 `topLeftRadius`/`bottomLeftRadius` = `theme.radiusLg`，
  末格同侧右侧圆角，中间格无圆角、只有右边框 —— 不是 N 个独立小方块
- **选中格**（光标所在格）：边框切 `theme.ring` + 3px 外环，与 `ShadcnInput` 的聚焦环一致；
  空格子上还有 1px 闪烁光标
- **disabled**：opacity 50%

## 需要注意

**为什么只用一个隐藏 `TextField`**：每格一个 `TextField` 的话，焦点要在格子间跳转，
粘贴只会落进当前那一个 field（填一格），退格要手写跳格，输入法组字更是无处安放。
浏览器里的 input-otp 同样是「单个 input + 自绘 slot」，Qt 侧照搬这套结构最省事也最稳。

**退格语义**：组件不自建光标状态，退格完全交给 `TextInput` 的默认行为
（删光标前一个字符），删完由 `textChanged` 重新分发到格子。所以退格删的始终是末尾，
不会出现「删当前格但后面字符不左移」的错位。

**`completed` 的触发口径**：以「长度达到 `length`」为准（`>=`），并且只在
从「未满 → 满」的跨越时发一次；某次操作后仍然是满的（例如把已满的值改写成另一个
等长值）不会再发。超长粘贴只发一次，payload 是截断后的值。
