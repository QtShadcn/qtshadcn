骨架屏：数据加载时的占位闪烁效果。

## 用法

```qml
// 矩形占位
ShadcnSkeleton { width: 200; height: 16 }

// 圆形占位（头像）
ShadcnSkeleton { width: 48; height: 48; radius: 24 }
```

## 视觉

- 背景色 `theme.muted`，圆角可配置
- 1.4s 循环 opacity 闪烁动画（1.0 ↔ 0.5）
