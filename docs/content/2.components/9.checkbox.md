# ShadcnCheckbox

基于 QQC.CheckBox（Basic style），自定义 indicator。

## 用法

```qml
ShadcnCheckbox { text: qsTr("同意条款"); checked: true }
ShadcnCheckbox { text: qsTr("订阅邮件") }
ShadcnCheckbox { text: qsTr("不可用"); enabled: false }
```

## 视觉

- 16px 方框 + rounded 5px + `bg-input/90`
- **选中**：`bg-primary` 底 + `primaryForeground` check 图标（14px，lucide check）
- **聚焦**：border 切 ring + 3px 外环（与 Input 一致）
- **禁用**：opacity 50%
- 键盘空格切换，indicator 与文本自动垂直居中
