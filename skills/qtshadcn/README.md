# QtShadcn Skills

给 AI 编码助手（Claude / Codex 等）使用的项目参考，格式对齐 [slidev/skills](https://github.com/slidevjs/slidev/tree/main/skills)。

## 结构

- `SKILL.md` —— 入口：项目定位、快速上手、所有组件/能力的表格索引
- `references/` —— 按类别拆分的详细参考（主题 / 构建 / 开发流程 / 图标 / 各组件类）

## 使用

AI 助手在项目里工作时，先读 `SKILL.md` 总览，再按需进 `references/` 查具体组件的用法、属性与开发坑。
